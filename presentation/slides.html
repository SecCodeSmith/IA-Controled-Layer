AI Control Layer

Policy-Enforcing Proxy for Agentic AI

Seven-stage pipeline • OWASP-grounded • Hot-reloadable policy • Real-time audit & alerting

The Problem

  • AI agents are dangerous: Tool calls can delete data, leak secrets, execute code
  • Prompt injection: Attackers override agent goals via model outputs, tool results, or chained calls
  • Over-provisioning: Agents get access to tools they don't need (EXCESSIVE AGENCY)
  • No audit trail: Compliance teams can't prove what data was accessed or masked
  • Incident response is slow: Deploy a policy fix, restart everything, wait for cold boot

Traditional API gateways don't understand LLM semantics. We need a proxy that speaks the language of agents.

Our Solution: Seven-Stage Pipeline

  1. Identity: Verify JWT, resolve user (role, location) → 401 if tampered
  2. Authorization: RBAC provisioning, residency check, approval gates → 403 if denied
  3. DLP: Detect & mask PII (email, PESEL, IBAN), secrets, exfiltration sequences → 403 or masked
  4. Policy: Signature + ML classifier + LLM judge for injection → 403 or escalate
  5. Behavior: Rate limit, loop guard, circuit breaker, risk scoring → 429/403 or quarantine
  6. Resource: Token budgets, cost limits, timeouts → 403 if exceeded
  7. Audit: Log every call, emit alerts (Excel + SSE), export reports

✓ OWASP-grounded: LLM Top 10 2025 + Agentic Top 10 2026 → All covered (except LLM08, LLM09 partial, ASI07)

Hybrid Defence: Deterministic + ML + Judge

Tier 1: Signatures

Regex patterns (OWASP + custom). Fast, zero false positives.

Tier 2: ML Classifier

Scikit-learn TF-IDF on 300-sample balanced dataset. F1 ≥ 0.85. Detects subtle injections.

Tier 3: LLM Judge

Ollama (Qwen 7B) for edge cases. JSON response. 20s timeout → FLAG.

Budgets, Behavior Analytics & Hot-Reload Policy

Token Budgets

Per-user limits: 10,000 tokens/day. Warn at 80%, block at 100%. Real usage from Ollama. Cost tracking: $1.00 USD/day limit.

Behavior Analytics

Per-user counters: rate limit (60/min), loop guard (5 identical calls), block-burst circuit breaker (5 blocks → quarantine). Risk scoring: anomalies (unusual tool for role, first destructive use, burst) raise score.

Hot-Reload Policy

File watcher polls every 1s. Valid change → version bump, cache clear. Invalid YAML → keeps last good, emits alert. No restart required.

Security Reporting & Audit

Real-Time Audit Log

Every call → CallRecord (timestamp, identity, tool, status, stage, rule, reason, raw vs delivered, tokens, latency, per-stage timing). JSONL file for durability.

Live Alerts

Non-ALLOW decisions → Alert (Excel file + SSE stream to dashboard). Admins see violations in real time. Export to XLSX.

Security Report

JSON + Markdown summary: KPI counts, top rules/users, OWASP coverage, posture score. Via API /api/reports/security.

Admin Dashboard

Live feed (real-time table), call detail (raw vs delivered, per-stage timing), audit export, policy viewer, attack suite runner.

Scalability Notes

Single process (Excel not thread-safe). Redis optional (in-memory fallback). Ollama ~100ms overhead per call on RTX 4070. MCP stdio processes spawned at startup (UTF-8 safe). No streaming yet (OpenAI passthrough coming P1).
